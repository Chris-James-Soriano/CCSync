Settings

Master schedule

Downloads everything stored in CCSync — the master schedule, faculty, subjects, sections, rooms, and which subjects are assigned to which sections — as one .xlsx file. User accounts and passwords are never included.

Download

Delete schedule

Permanently deletes every scheduled class block in the master schedule. Subjects, sections, faculty, rooms, section assignments, and your account are all kept. Use “Generate schedule automatically” on the Master Schedule tab to build it again. This cannot be undone.

Import schedule

Imports a backup file downloaded from this page and replaces the current data with its contents: the schedule, faculty, subjects, sections, rooms, and section assignments are all overwritten. Your user account stays. If the file is invalid, nothing is changed.
